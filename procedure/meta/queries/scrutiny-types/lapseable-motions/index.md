## Queries for motions that need checking at the end of a session

At the end of a Parliamentary session all outstanding motions lapse which means the question will not be put before the House. Government and Members would need to table the motions again in the new session if they wanted to see a resolution. 

These queries are used by librarians to check work packaged things at the end of the session. The queries are looking for specific motions that have been tabled and checking to see if they have a corresponding outcome step actualised on the same work package. If a motion is still active on the work package, librarians will check the work package and if needed actualise a "Motion lapsed" step that goes with the active motion. Where there are no results for a query, no action is required. 

At the end of each session, each session must be checked. The date in the query will need to be changed to the start date of the session that has ended. Session dates can be found at [Parliamentary Time](https://api.parliament.uk/egg-timer/sessions).
